BITÁCORA - RUEDA LIBRE

== 1. Petición del documento (Network) ==
URL completa: http://127.0.0.1:5500/index.html
Protocolo:    http
Host:         127.0.0.1
Puerto:       5500
Ruta:         /index.html
Método:       GET
Código:       200 OK (el servidor encontró y envió la página)

Ruta inexistente: http://127.0.0.1:5500/promociones.html
Código:       404 Not Found (el recurso no existe en el servidor)

== 2. Roles de HTML, CSS y JavaScript ==
HTML: estructura y contenido. Ej: la tabla de tarifas.
CSS:  presentación visual. Ej: colores de marca y menú horizontal.
JS:   comportamiento. Ej: validar el formulario de reservas.
